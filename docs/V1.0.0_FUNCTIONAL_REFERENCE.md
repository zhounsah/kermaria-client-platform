## Comportements metier majeurs

### Signup et activation

- Le signup cree une demande en attente apres verification anti-bot.
- L'approbation admin cree le client et l'utilisateur portail.
- Le mot de passe est defini ensuite via un lien one-shot.
- Aucune creation AD automatique n'est a supposer sans verification
  complementaire du flux cible.

Source d'historique :

- [`V0.26_SELF_SERVICE_SIGNUP.md`](V0.26_SELF_SERVICE_SIGNUP.md)
- [`v0.38/V0.38_SITE_AD_ALIGNMENT.md`](v0.38/V0.38_SITE_AD_ALIGNMENT.md)

### Paiements et abonnements

- One-shot : facture / document commercial puis paiement Stripe, PayPal ou
  virement selon le cas.
- Recurring : le checkout facture cree les souscriptions localement, emet une
  facture initiale, puis active apres paiement.
- Les renouvellements `billing` sont pilotes localement par worker, pas par un
  plan PSP natif.

Source d'historique :

- [`V0.21_PAYMENT_CHANNELS.md`](V0.21_PAYMENT_CHANNELS.md)
- [`V0.22_SUBSCRIPTIONS.md`](V0.22_SUBSCRIPTIONS.md)
- [`V0.29_STRIPE_PAYMENTS.md`](V0.29_STRIPE_PAYMENTS.md)
- [`V0.36_PANIER_UNIFIE_ABONNEMENTS_FACTURES.md`](V0.36_PANIER_UNIFIE_ABONNEMENTS_FACTURES.md)

### Contenus administrables et packs publics

- Les packs publics sont une couche de presentation sur les offres facturables.
- Les contenus legaux, a propos et fiches techniques sont admin-editables.
- Le mapping technique et le provisionnement restent dans le code.

Source d'historique :

- [`V0.32_PUBLIC_PACKS.md`](V0.32_PUBLIC_PACKS.md)
- [`V0.33_CONTENUS_ADMINISTRABLES.md`](V0.33_CONTENUS_ADMINISTRABLES.md)

### Telechargements clients

- Les fichiers telechargeables ne vivent pas dans `public/`.
- Les metadonnees et droits vivent en base.
- Les binaires passent par `API-INTERNAL` et `DOWNLOAD_STORAGE_ROOT`.

Source d'historique :

- [`V0.37_CENTRE_TELECHARGEMENTS_CLIENT.md`](V0.37_CENTRE_TELECHARGEMENTS_CLIENT.md)

### KoXo et alignement identite

- L'export KoXo est un flux prive et encadre.
- Les champs necessaires a l'export ont ete renforces.
- La synchronisation doit etre lue comme un flux outille, pas comme une
  source de verite pour les secrets ou l'authentification.
