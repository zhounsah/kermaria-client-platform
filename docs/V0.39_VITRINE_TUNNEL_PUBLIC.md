# V0.39 - Vitrine publique et tunnel de conversion

Statut : **implante dans le depot**. Cette V0.39 reprend la vitrine publique
pour la rendre plus lisible en acquisition, sans modifier le checkout, les
abonnements ni le modele de donnees.

## Ce que livre V0.39

- home publique recentree sur la promesse commerciale, la reassurance, les
  cas d'usage et les points d'entree du parcours ;
- header public moins centre sur `Connexion`, avec CTA principaux orientes
  vers les offres, l'inscription ou le contact selon `SIGNUP_ENABLED` ;
- page `/offres` relue en deux temps :
  - cartes packs d'abord ;
  - comparatif detaille ensuite ;
- transport du contexte pack dans le tunnel public :
  `pack`, `commitment`, `payment` et, si besoin, `offer` ;
- page `/contact` capable de reprendre un pack selectionne avec un resume
  lisible avant l'envoi du formulaire ;
- page `/signup` capable de reprendre le pack selectionne, d'exposer les
  etapes du parcours, puis de conserver ce contexte dans la demande ;
- metadata publiques et JSON-LD renforces pour mieux decrire la vitrine ;
- aucune migration SQL, aucune extension du module V0.33 de contenus
  administrables.

## Perimetre reel

### Pages publiques concernees

- `/`
- `/offres`
- `/contact`
- `/signup`

### Composants principaux

- `PublicShell`
- `PublicPackCard`
- `PublicPackComparisonTable`
- `PublicPackOverviewGrid`
- `PublicPackSelectionSummary`
- `ContactForm`
- `SignupForm`

### Regles de tunnel

- si `SIGNUP_ENABLED=true`, le CTA pack principal reste l'inscription ;
- si `SIGNUP_ENABLED=false`, le CTA pack principal bascule vers le contact ;
- dans les deux cas, le contexte du pack choisi reste explicite jusqu'au
  formulaire final.

## Ce que V0.39 ne change pas

- aucun changement du tunnel checkout `/souscrire` / `/panier` ;
- aucune extension de `managed_content_entries` ;
- aucune mutation du moteur de provisioning ou des rails Stripe / PayPal /
  billing ;
- aucune nouvelle table ni migration.

  d'erreurs preexistantes hors perimetre V0.39 (notamment downloads et
  `HeaderCartDrawer`) ;
- le contenu nouveau de la home reste code en dur dans V0.39 ; aucune
  extension CMS n'est introduite dans ce lot.
