# Storefront v1.4.0.4 — Breadcrumbs & final polish

## Scope

Cette passe reste limitée au WebPortal public. Elle ajoute un fil d’Ariane aux 21 routes Storefront de `/services` et `/tarifs`, sans modifier le contenu administrable, le seed, API-INTERNAL, Billing, MariaDB, Stripe, le provisioning, `/formules` ou `/diagnostic`.

## Architecture

- Le composant `ServiceBreadcrumb` existant est généralisé pour recevoir une liste de niveaux.
- Les libellés et chemins sont résolus par un registre fermé dans `storefront-content.ts`.
- La structure du breadcrumb dépend uniquement de la route et du slug ; elle n’est jamais lue ni écrite depuis le CMS.
- La page courante utilise `aria-current="page"` ; les niveaux précédents restent navigables.
- Le style `.service-breadcrumb` existant est conservé, avec uniquement `flex-wrap` pour les petits écrans.

## Structured data

Le renderer Storefront réutilise `JsonLd` et `breadcrumbJsonLd` déjà présents dans `lib/seo.tsx`.
Le même tableau de niveaux alimente le breadcrumb visible et le `BreadcrumbList`, avec `PUBLIC_SITE_URL` (`https://zachary-it.fr`) comme base canonique.
