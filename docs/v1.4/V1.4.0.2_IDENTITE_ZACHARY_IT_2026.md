# Zachary IT 2026 - Identite visuelle WEBPORTAL

## Statut

Identite visuelle integree au WEBPORTAL sans modification de comportement
fonctionnel, de catalogue, de paiement, de provisioning ou de donnees.

## Source de verite

Le pack integre au depot est disponible dans
[`apps/webportal/public/brand/`](../../apps/webportal/public/brand/).

- `logo/` contient les SVG officiels a utiliser tels quels ; le monogramme ne
  doit jamais etre recompose en CSS ou SVG inline ;
- `tokens/tokens.css` et `tokens/tokens.json` portent les tokens verrouilles ;
- `favicon/` contient les icones officielles et le manifest ;
- `README.md` decrit les usages autorises et interdit notamment tout effet ou
  recoloration du logo.

La baseline officielle est :

> Votre informatique. Gérée, sécurisée, disponible.

## Integration

- `app/brand-tokens.css` reprend les tokens officiels et `globals.css` remappe
  progressivement les variables historiques vers ceux-ci ;
- `components/BrandLogo.tsx` ne reference que les fichiers SVG de
  `public/brand/logo/` ;
- `app/icon.svg`, `public/favicon.ico`, les metadata et le manifest utilisent
  les icones officielles ;
- Inter est la police de contenu et JetBrains Mono reste reservee aux statuts
  et libelles techniques ;
- le header, footer, vitrine, formules, portfolio statique, espace client et
  administration partagent la meme palette, iconographie Lucide et echelle de
  surfaces.

## Garde-fous

Cette livraison ne modifie ni les routes, canonical, sitemap ou contrats SEO,
ni le code Billing V2, Stripe, signup, provisioning, API ou migrations. Les
tarifs restent exclusivement servis et calcules par l'API interne.

Les validations a executer avant une publication sont : `lint`, `typecheck`,
build WEBPORTAL, `test:seo`, `test:brand`, `test:formules` et
`test:billing-legacy`, puis un controle de rendu desktop et mobile.
