# v2.1.1-hotfix.4 — Alignement des boutons de Tarifs

Dans `/tarifs`, les cartes sans lien secondaire plaçaient leur bouton
principal plus bas que les cartes voisines. Le conteneur des actions réserve
maintenant une seconde ligne, y compris lorsque « Découvrir le service »
n'est pas affiché.

La modification porte uniquement sur la grille CSS des cartes tarifaires.
Elle ne modifie ni les prix, ni les devis, ni les parcours de commande, ni
les règles fiscales. Aucun changement API-INTERNAL ou migration SQL n'est
nécessaire.

Vérification visuelle du candidat CSS sur la page publique, à 1920 px de
large : avant correction, les boutons des deux premières rangées présentaient
31 et 32 px d'écart ; après correction, les 10 rangées contenant plusieurs
cartes avaient un écart vertical nul. À 390 px, aucun débordement horizontal
de la page n'a été constaté. Le filtre de catégorie a été actionné et les
cartes se sont mises à jour sans erreur console.

Déploiement ciblé sur le WebPortal SRV-12. La release précédente reste
disponible derrière le lien `/opt/kermaria/webportal` pour un rollback
immédiat en cas d'échec des contrôles de santé ou de rendu.
