## Scope
WEBPORTAL-only follow-up security release on top of `v2.0.2.7`:
- `/api/formules/souscrire` checks for a session and validates the double-submit CSRF token before reading or validating the commercial JSON payload;
- Billing V2 payload, rail and idempotency validation cannot run before the CSRF gate on an authenticated mutation;
- the auth contract asserts this required ordering so the regression cannot silently return;
- no API-INTERNAL implementation change and no SQL migration are part of this release.
