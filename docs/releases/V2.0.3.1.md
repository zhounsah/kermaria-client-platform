# Release v2.0.3.1

Date: 2026-10-01
Tag: `v2.0.3.1`

## Scope

Correctif ciblé du parcours panier Billing V2.

- après authentification, un panier client `open` existant reste prioritaire sur
  un panier anonyme concurrent ; le panier anonyme perdant est expiré sans
  fusion des lignes commerciales et son cookie est supprimé ;
- une ancienne URL de souscription est réalignée vers le panier client retenu ;
- le panier peut être vidé après confirmation, tout en conservant son
  identifiant et la protection par version optimiste ;
- les URL de succès et d'annulation du checkout sont construites depuis
  l'origine publique du portail ;
- les contrats BFF et storefront couvrent ces comportements.
