# Release v2.0.3.2

Date : 2026-10-04. Livraison preparee depuis le tag exact `v2.0.3.2`.

## Perimetre

- Renvoi administrateur de l'e-mail de verification d'une inscription encore
  en attente, avec rotation du jeton et controle de concurrence.
- Reconciliation du provisioning apres confirmation d'un paiement Stripe par
  relecture fournisseur ; conservation des controles de preparation et du
  traitement technique distinct pour les VPS.
- Revue de preparation du client accessible depuis sa souscription.
- Qualites KoXo DEV : demandes persistantes par identite, revisions, reprises,
  et acquittement uniquement apres preuve CSV + fiche KoXo + groupes AD.
- Quotas et stockage KoXo cibles, isolement DEV et controles de recherche AD.
- Preparation automatique du CSV pour les changements de qualites, sans
  lancement de KoXo. L'import avec remplacement reste **manuel**, par decision
  du titulaire. La creation d'identite conserve son circuit existant.

Le groupe neutre configure represente l'absence d'acces ; il n'annule aucun
droit par lui-meme. Les anciens groupes doivent effectivement avoir disparu.
Les automatismes de remplacement des qualites sont reportes hors de ce lot.

terminee. Details et preuves dans `docs/DEV_E2E_NOE_VALBRUME.md`.

## Exploitation

- Migration098 deja appliquee a `kermaria_dev`, apres sauvegarde. Pas de DDL au
  demarrage. Le worker qualites reste explicitement DEV et desactive par defaut.
- L'API PROD conserve le contrat KoXov2 de son recepteur actuel. Les scripts v3
  ne doivent pas remplacer la copie PROD partagee ; le deploiement generique
  refuse cette combinaison. La copie DEV est isolee sur SRV-21.
- Pour un changement de qualites : publier/reconcilier, attendre le CSV a jour,
  importer les qualites avec remplacement sur les seules identites visees,
  fermer la console et controler CSV/KoXo/AD. Le worker n'acquitte pas un simple
  HTTP202 et ne relance pas KoXo en attendant l'operateur.
- La panne WAN/DNS externe n'est pas resolue par cette release. Le relais
  Stripe temporaire de recette a ete retire ; aucun DNS global n'a ete modifie.
