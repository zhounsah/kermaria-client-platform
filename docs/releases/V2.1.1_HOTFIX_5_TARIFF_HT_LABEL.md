# v2.1.1-hotfix.5 — Légende HT simplifiée sur Tarifs

Dans `/tarifs`, les montants sous les prix TTC affichent désormais
`(8,25 € HT)` au lieu de `(8,25 € HT, estimation France)` pour l'exemple à
9,90 € TTC. Le même format s'applique aux autres prix, paliers et frais
présentés par le catalogue.

Seul le libellé du WebPortal change. Les montants TTC, la ventilation HT
fournie par API-INTERNAL, les devis, les calculs fiscaux et les paiements
restent inchangés. Aucun changement API-INTERNAL ou migration SQL n'est
nécessaire.

Contrôles du candidat : `npm run check:web` et `npm run test:catalog`
réussis ; le lint ne rapporte que trois avertissements préexistants.

Déploiement ciblé sur le WebPortal SRV-12. La release précédente reste
disponible pour un retour immédiat si la page ou le service échoue.
