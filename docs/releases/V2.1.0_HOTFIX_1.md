# Correctif v2.1.0 — caractéristiques des serveurs

La version affichée reste **v2.1.0**. Le tag technique
`v2.1.0-hotfix.1` identifie ce correctif sans déplacer le tag initial
`v2.1.0`.

Les capacités issues du catalogue Billing V2 sont désormais présentées avec
les termes demandés par le propriétaire : `vCPU`, `Go de RAM` et `Go SSD`.
Par exemple, `4 unités de calcul · 8 Go de mémoire · 80 Go d'espace de
stockage` devient `4 vCPU · 8 Go de RAM · 80 Go SSD`. Cette présentation est
partagée par les offres de serveurs et leurs parcours de choix. Les valeurs,
les prix et les règles de commande ne changent pas.

Contrôles avant livraison : contrats Formules, contenus administrés et VPS,
typecheck WebPortal, lint sans erreur et build WebPortal réussis. Le lint
signale trois avertissements préexistants hors de ce correctif.

Seul le WebPortal doit être reconstruit et livré en DEV puis en PROD. Aucune
migration MariaDB ni modification de l'API ou de ses configurations n'est
nécessaire. Les empreintes des archives et les vérifications après livraison
seront ajoutées à cette note une fois les services contrôlés.
