# v2.1.1-hotfix.3 — Simplification du texte de la page Tarifs

Ce correctif WebPortal retire la phrase fiscale répétée au-dessus du catalogue
et dans chaque carte de `/tarifs`. Les prix TTC, la ventilation HT indicative
et les règles de devis et de paiement restent inchangés.

Le champ de présentation `taxNotice`, devenu inutilisé, est retiré de la
projection du catalogue public et du contrat TypeScript partagé. Le test de
contrat vérifie que la phrase ne réapparaît pas.

Déploiement ciblé : WebPortal sur SRV-12. Aucune migration SQL, modification
API-INTERNAL, configuration Stripe ou BPCE n'est requise. Le lien actif
`/opt/kermaria/webportal` permet de revenir immédiatement à la release
précédente si les contrôles de santé ou la page publique échouent.

Contrôles du candidat : `npm run test:catalog` et `npm run check:web` réussis.
Le lint rapporte trois avertissements préexistants, sans erreur.
