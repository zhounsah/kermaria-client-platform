# React et Next.js

Lire la documentation de la version installée dans `node_modules/next/dist/docs/` avant de changer une API Next.js. Garder les métadonnées, le chargement de contenu et les accès BFF côté serveur. Limiter les composants client au comportement interactif. Préserver le HTML du H1 et des liens au premier rendu, éviter les effets qui changent la structure du contenu après hydratation, et vérifier lint, types et build.
