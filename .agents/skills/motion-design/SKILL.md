# Mouvement

Employer CSS et Web Animations API pour les effets présents ; justifier une bibliothèque avant de l'ajouter. Réserver le mouvement à l'entrée, au changement de page, au retour d'état et à l'orientation. Garder une durée brève et une distance faible. Le bouton de pause et `prefers-reduced-motion` doivent neutraliser les effets non essentiels.
