# Recette navigateur

Lancer `npm.cmd --prefix apps/webportal run test:e2e` depuis la racine. La configuration démarre un serveur local avec vitrine activée et mock de développement ; elle ne prouve aucune intégration interne réelle. Tester l'accueil, la navigation, le menu mobile, le mouvement réduit, les erreurs de page et le débordement. Compléter les tests de contrats existants pour le SEO et le métier.
