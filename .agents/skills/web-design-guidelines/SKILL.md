# Revue de page publique

Vérifier hiérarchie H1–H3, contraste, focus visible, cibles tactiles, ordre clavier, navigation mobile et absence de débordement. Garder le texte métier dans le DOM et les éléments décoratifs hors de l'arbre accessible. Vérifier canonicals, robots, sitemap, JSON-LD et routes privées avant de toucher au layout ou au routage.
