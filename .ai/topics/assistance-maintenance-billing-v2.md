# Assistance et maintenance Billing V2 — livraison DEV du 2026-10-29

Six services mensuels sont préparés dans la migration `103_assistance_catalog.sql` : trois particuliers à 9,90 / 19,90 / 39,90 € TTC et trois professionnels à 19 / 39 / 69 € HT indicatifs par poste pour une opération française taxable. Le catalogue Billing V2 porte les prix TTC correspondants et les bornes de quantité ; le portail ne recalcule pas les prix.

Les pages `/assistance-maintenance`, `/assistance-maintenance/particuliers` et `/assistance-maintenance/professionnels` utilisent le catalogue public et reprennent les prestations de la grille commerciale approuvée. La migration publie les prix en mode devis ; le panier direct ne s'affiche que si l'API confirme plus tard son éligibilité. Le mock présente les prix, sans commande directe. Aucun service de cette gamme ne possède de règle de provisioning AD ou KoXo pour les postes externes.

La migration 103 a été appliquée sur `BASE-SQL-01.home.bzh` / `kermaria_dev` avant le démarrage de la nouvelle API DEV. Les six prix et les bornes ont été relus en base ; Web DEV sert les pages et le catalogue. Aucun paiement, abonnement fournisseur ou déploiement PROD n'a été effectué.
